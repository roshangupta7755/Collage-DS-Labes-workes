📘 Collage DS Labs Workes

A beautifully organized and clean repository containing all Data Structure Lab Programs. This README makes the project easy to navigate, understand, and use.

🚀 About This Repository

Ye repository BCA / Engineering students ke liye perfect hai jo Data Structure (DS) Lab Programs ko proper format me dekhna chahte hain. Har lab program ko neatly arrange kiya gaya hai with clear file names.

📥 How to Run

Clone the repository

Open the folder

cd Collage-DS-Labes-workes

Compile any C file

gcc filename.c -o output

Run the program

./output
